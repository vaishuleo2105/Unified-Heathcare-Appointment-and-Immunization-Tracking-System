P[42] (Style: normal): SYNOPSIS
P[43] (Style: normal): FreightOpt is a web-based intelligent freight planning and demand prediction system designed to support freight analysis through historical data, machine learning and interactive visualization. Freight-related information can be difficult to interpret when it is maintained as separate datasets or analysed manually. FreightOpt brings the relevant data processing, predictive modelling and visualization activities into a unified application.
P[44] (Style: normal): The system supports administrator and government-planner workflows. Freight-related data for the period 2020–2026, covering 38 districts of Tamil Nadu, is organized and prepared for predictive analysis. The system performs data preprocessing, feature selection and an 80:20 training and testing split before training regression models. Three machine learning approaches are implemented: Ridge Regression, Random Forest Regressor and Gradient Boosting Regressor, of which the Gradient Boosting model performs best. A multi-pillar Infrastructure Deficit Index and a Linear Programming based budget optimizer (using SciPy's linprog) are also incorporated to support planning decisions.
P[45] (Style: normal): The application uses Streamlit for the interactive client interface, FastAPI with Pydantic for REST API services and request/response validation, SQLite for data storage and Folium for interactive map visualization. The backend currently exposes seven API endpoints. Analytical views present freight-related patterns and prediction results in a form that can be interpreted by planning users.
P[46] (Style: normal): The main objective of FreightOpt is to provide a structured, data-driven environment for freight demand analysis and planning. By combining historical data, predictive modelling, an infrastructure deficit index, budget optimization, API services, database management and visualization, the system provides a foundation for informed freight planning and can be extended with additional datasets, optimization methods and deployment capabilities.

P[51] (Style: normal): 1.1 PROJECT OVERVIEW
P[52] (Style: normal): Freight transportation supports industrial activity, trade and regional economic development. Planning freight movement requires the ability to understand historical freight patterns and estimate future demand. When data is maintained in separate files and analysed manually, planners may need to perform repeated calculations and compare multiple views before obtaining useful insights.
P[53] (Style: normal): FreightOpt is a web-based intelligent freight planning and demand prediction system proposed to address this requirement. It provides a unified environment for storing, processing, analysing and visualizing freight-related data and for generating demand predictions using machine learning, for 38 districts of Tamil Nadu.
P[54] (Style: normal): The system uses historical freight-related data covering the period 2020–2026. Relevant variables are selected and prepared for modelling. The processed data is divided into training and testing subsets using an 80:20 ratio. Ridge Regression, Random Forest Regressor and Gradient Boosting Regressor are trained and evaluated as alternative regression models, with Gradient Boosting selected as the best performer.
P[55] (Style: normal): The platform supports two principal user roles: Administrator and Government Planner. The Administrator-oriented functions support system/data management, while the Government Planner-oriented functions focus on analysing freight information, viewing predictions, the Infrastructure Deficit Index, budget optimization results, and using visualizations for planning.
P[56] (Style: normal): FreightOpt combines Streamlit for the interactive application interface, FastAPI and Pydantic for REST services and validation, SQLite for persistent data storage, scikit-learn based regression models for prediction, SciPy for Linear Programming based budget optimization, and Folium for geographic visualization. The system is designed as a project-level application and provides a foundation that can be extended for larger-scale freight planning.

P[366] (Style: normal): 4.9 BUDGET OPTIMIZATION
P[367] (Style: normal): Purpose
P[368] (Style: normal): The Budget Optimization Module is designed to support allocation of an available infrastructure budget across districts. The module uses Linear Programming to formulate the allocation problem under specified budget and planning constraints. The objective is to determine an allocation that considers the infrastructure requirements represented by the system's planning indicators.
P[369] (Style: normal): How It Works
P[370] (Style: normal): The optimization process begins by generating or retrieving the candidate district-level planning requirements. The available budget and relevant allocation constraints are then represented mathematically as a linear programming problem. The optimization problem is solved using SciPy's scipy.optimize.linprog function. The resulting solution provides the allocation values for the candidate planning activities.

The system converts the planning information into the coefficient matrices and bounds required by linprog. After solving the optimization problem, the resulting allocation values are processed and presented through the Streamlit interface.The optimization results can be combined with the Infrastructure Deficit Index and freight demand information to support district-level planning analysis.

P[474] (Style: normal): FreightOpt provides a unified web-based approach to freight analysis, infrastructure assessment and demand prediction for Tamil Nadu. The system brings together historical freight data, preprocessing, machine learning, an infrastructure deficit index, Linear Programming based budget optimization, database management, REST API services and interactive visualization within a single application.
P[475] (Style: normal): The project uses freight-related data for 38 districts of Tamil Nadu covering 2020–2026 and applies an 80:20 train-test strategy. Ridge Regression, Random Forest Regressor and Gradient Boosting Regressor are implemented and compared as alternative regression approaches, with Gradient Boosting selected as the best-performing model for freight demand prediction.
P[476] (Style: normal): The application uses Streamlit for the interactive interface, FastAPI and Pydantic for backend services and validation, SQLite for data storage, SciPy for budget optimization and Folium for map-based visualization. These components provide a structured project-level architecture in which data, predictions and allocation outputs can be presented to administrators and government planners.
